# holocubic控制台 v1.0.0

双击上一级目录的 `holocubic控制台.exe`。请保留整个程序目录；不需要另外安装 Node.js、Python 或 .NET。

- 顶部语言选择支持中文、繁体中文、英语、日语、德语，保存到本机并即时切换控制台界面。软件设置中的设备管理支持重命名。
- 文件管理顶部精简为设备名称和 IP；传输队列分为全部、进行中、已结束，显示进度、速度、预计剩余时间与文件明细。
- 电脑服务可点击“进入设备应用”，启动当前设备上已安装的对应应用，并沿用自动配置及独立控制窗口。
- 常用设置恢复默认时，天气地址填入 `new york`，点击保存后写入设备。
- 左上角“扫描局域网设备”按实际网卡子网扫描。发现的 Cubic 会自动加入列表，保留已有名称，不切换当前设备。也可以手动添加 IP 或 `.local` 地址。
- 首页显示设备真实应用、服务和连接状态。应用图标读取设备 `/sd/apps/<应用ID>/main.png`，没有图标时使用占位图。
- 打开设备应用会弹出独立控制窗口，原主页面保留。窗口支持 F5 刷新、Alt+左/右 后退或前进。
- 媒体、商店、网络、设备服务和固件管理复用设备完整 Web 页面；应用安装、媒体转换和上传进度由对应页面显示。
- 电脑服务包含音乐同步、电脑监控、桌面投屏、Holopet 和 Codex Buddy。每项显示设备对应应用的实际图标，并提供进入设备应用、启动、停止、服务页面、设置和随控制台启动选项。
- 默认在相关设备应用打开时自动启动并配置对应电脑服务；内嵌页面内切换设备应用也会被检测到。手动停止的服务保持停止，重新打开相关应用时恢复自动配置。
- 投屏支持显示器、已连接虚拟显示器、指定区域、适配方式、帧率和质量。数据通过与旧 App 兼容的 DMJ1 WebSocket 协议发送。
- 高级工具包含串口配网、串口终端、运行日志、下载记录和设备开发工具。
- 串口配网使用旧 App 的 `@CUBIC_WIFI/1` 协议。连接 USB 数据线，在设备上打开 **WiFi Setting Guide**，选择串口后扫描 Wi-Fi，再输入密码连接。软件复用串口连接，等待握手和联网结果，成功取得的 IP 会自动加入设备列表。

电脑服务端口：SMTC Music 17865、电脑监控 17322、桌面投屏 8787、Holopet 17321、Codex Buddy 8788。外部程序已提供的服务可以复用；控制台不会停止由其他程序启动的服务。部分硬件温度、功耗需要在电脑监控设置中手动启动管理员传感器。

软件设置与日志保存在 `%APPDATA%\holocubic控制台`。设备 Wi-Fi 密码不保存到控制台配置中。关闭控制台会退出由它启动的后台服务。

## 文件管理（v0.4.0）

左侧“文件管理”提供 SD 卡目录树、面包屑/可输入路径、前进后退、排序和当前目录搜索。支持 Ctrl 多选、Shift 连选、空白区框选、右键菜单、Ctrl+C/X/V、F2、Delete 和 Alt+方向键。

- 新建目录、文件/目录上传、拖入上传、批量下载、复制、剪切移动、重命名和永久删除。
- 重名可覆盖、跳过、自动改名，并可应用到整批任务。覆盖文件采用临时文件和备份交换；目录覆盖会合并内容。
- 传输队列显示文件明细、总进度、当前文件进度、字节数、速度和预计时间。支持取消、失败重试和打开下载位置。重试会重新处理该批任务，同名已完成文件仍按冲突选择处理。
- 切换页面或设备不终止原传输，任务始终绑定发起时的设备。默认串行传输，保护 SD 卡响应。关闭软件会提示取消未完成任务。
- 图片和文本通过独立窗口查看，文本支持保存、另存为、Ctrl+S 和未保存提醒。文本预览上限 2 MB，图片上限 12 MB。保存时会检查设备文件是否已被其他操作修改。
- 设备没有回收站，删除需要确认。暂不提供断点续传、压缩解压、跨设备直接复制和全盘内容搜索。设备当前只开放 /sd，未返回修改时间时显示“—”。
- 文件浏览与传输使用 FS 接口，重命名、移动、删除使用自动发现的 DevTools 接口；必要时自动启动设备已有的 DevTools 服务。设备必须安装 DevTools。

本次验证包括脚本语法、真实设备测试目录上的上传下载内容一致性、复制/重命名/移动/删除、文本保存、进度与速度事件，以及页面导航、多选、搜索和复制快捷键。

## 软件更新

软件设置支持导入本地 ZIP 更新包，以及填写 HTTPS 更新源后检查、下载、校验和安装更新。安装前显示版本并确认重启，保留设备列表与软件设置，并备份上一版程序。当前尚未配置线上发布地址。

开发者更新 `resources/app/package.json` 版本号、重新编译本机工具后，运行 `build-update.ps1` 生成更新包及更新清单模板。将清单中的下载地址与更新说明填写完整，再托管到自己的 HTTPS 地址。更新包版本必须高于当前软件版本。本更新机制更新应用与本机服务，Electron 运行时升级通过完整程序包发布。

## 源码与检查范围

界面及 Electron 主进程源码位于 `resources/app`；本机工具源码位于 `resources/app/native-source`，使用 .NET 10 编译。原 App 的硬件采集与内置服务源码按照原 GPL 许可证保留，参见 `LICENSE` 和 `THIRD_PARTY_NOTICES.md`。

本版完成编译/语法检查、设备状态和真实图标读取、五项服务 UI、四项内置服务启动/健康接口、自动配置去重/手动停止策略、串口配网协议以及弹窗入口保留主页面的检查。串口写入 Wi-Fi 凭据、所有设备应用的实际功能和不同硬件上的投屏效果由用户验收。

### 自动串口日志

默认自动连接 USB 串口并记录设备输出。一个未被其他设备绑定的唯一串口会自动连接；多个串口请在高级工具 → 串口终端选择并连接一次，保存当前设备的串口与波特率。USB 中断后自动重连；手动断开暂停本次连接，重启控制台或手动连接可恢复。串口配网与终端复用连接，保持 DTR / RTS 关闭。

日志保存在 `%APPDATA%\holocubic控制台\serial-logs\设备IP`：按日、串口和 20 MB 分卷保存完整输出，`incidents` 保存异常前后文，`events-日期.jsonl` 保存死机/重启事件及启动原因。相同启动过程中的多条标志只记作一次重启；CPU 使用率、普通网络离线不会标成死机。高级工具 → 串口终端或运行日志可打开日志文件夹。只有网络连接而没有 USB 串口时，不会产生串口日志。

打开软件设置、高级工具、电脑服务时保留当前页面和滚动位置，背景轻微虚化；设备 Web 页面使用当前画面的临时内存快照作为背景，关闭面板后恢复原页面，不刷新或重新导航。
传输队列中，单文件任务仅显示一次文件名；多文件任务在折叠的明细中逐项显示。

首页设备应用直接列出全部已安装应用，在应用区域内滚动查看；刷新设备状态时保留列表滚动位置。
