# Holopet 多 AI 状态同步

在控制台打开「电脑服务 → Holopet → 设置」。设备进入 Holopet / Clawd Monitor 后，继续自动配置电脑 IP、17321 端口和 /events。

## 当前 ChatGPT / Codex 客户端的本地工作任务

默认开启「自动同步本地任务日志」，从现有客户端日志中增量提取任务状态、模型、推理强度以及上下文 Token 占用。无需重启 ChatGPT，也不依赖 Hook。仅在内存中提取白名单元数据，不保存或转发聊天正文；支持暂停同步。

额度按实际的模型额度桶和统计窗口匹配。当前模型没有匹配数据时显示未知；不会把 Spark 额度当作其他模型的额度，也不会将每周窗口当成五小时窗口。

## ChatGPT 账号与用量（v0.4.6）

1. 在 Holopet 设置的「ChatGPT 账号与用量」点击「连接 ChatGPT 账号」。控制台调用官方 App Server，在默认浏览器打开官方登录页面；请自行登录与当前客户端相同的账号。
2. 浏览器回调受限时，可取消登录后选择「使用设备码登录」，在官方页面输入控制台显示的代码并授权。
3. 登录成功后，控制台每分钟读取额度及使用统计；可「立即刷新用量」。各额度组分别显示已用、剩余和实际重置时间。Token 统计展示接口返回的累计、单日最高、连续使用、最长任务及最近每日用量。未返回的字段显示 --。
4. 「断开账号连接」仅退出控制台的独立登录。现有客户端登录不受影响。

运行组件使用本机已安装的 ChatGPT / Codex 客户端中的 codex.exe。账号配置、登录凭据、SQLite 缓存及临时文件均使用 `%APPDATA%/holocubic控制台/chatgpt-account`，不复制或修改现有客户端的 `.codex` 登录数据。凭据仅由官方运行组件保管，不进入界面、设备事件或控制台日志。

设备收到当前模型对应的额度、重置时间及汇总统计；每日列表只在控制台显示。设备固件是否显示新统计字段取决于其支持情况。第三方 AI 的状态不混入 ChatGPT 额度。上下文仍来自本地任务日志，与账号额度分别读取。

额度重置时间不是订阅到期日，官方接口没有提供订阅到期日。账号用量指官方 Codex 服务返回的统计，不代表所有普通 ChatGPT 聊天的完整 Token 账单。

官方账号接口：https://learn.chatgpt.com/zh-Hans/docs/app-server

「可选 Hook 接入」供支持生命周期 Hook 的客户端使用。配置后重启客户端；若提示 Hook 待审查，请自行审查并信任。控制台不会修改客户端的安全设置。写入 Hook 配置不等同于已经收到事件。
安装只添加本服务的生命周期处理，原有 Hook 保留；原配置备份在控制台数据目录的 integration-backups 中。适配器复用控制台自带的 Electron Node 运行时，不需要另装 Node.js。
已存在的旧 codex-status.cjs 接入也能继续使用。

## 常见 AI 网页

1. 点击「打开浏览器扩展文件夹」。
2. Edge 打开 edge://extensions，Chrome 打开 chrome://extensions，开启开发者模式，选择「加载解压缩的扩展程序」，选择 ai-browser-extension 文件夹。
3. 刷新已打开的 AI 网页，在设备上打开 Holopet / Clawd Monitor。

已加入 ChatGPT、Claude、Gemini、DeepSeek、Kimi、豆包、通义千问和 Grok 的站点适配。只在这些站点运行，向本机 127.0.0.1:17321 发送状态。没有云端转发、账号绑定或 API Key。
提交问题显示思考中；检测到生成结束显示完成；点击停止回到空闲；检测到生成错误显示出错。等待确认、执行和协作等细分状态由本地任务 Hook 提供。
网页优先观察生成请求和响应流的生命周期，并用生成/停止按钮补充识别。不会读取请求正文或生成内容，不复制或额外消费响应流。站点、语言和页面版本差异会影响自动识别。未识别到生成信号时，不会假装任务完成。扩展弹窗可暂停自动同步或手动发送状态。
浏览器内多个任务并行时，优先显示仍在生成的任务。控制台显示最后收到的来源、状态和时间；「发送测试状态」只验证推送链路，不能证明真实 AI 活动已经接入。

**范围：**普通网页聊天通过浏览器扩展同步；第三方原生桌面 AI 客户端中的普通聊天，若不能加载浏览器扩展且不提供生命周期事件，暂不能自动读取。可用对应网页版或扩展弹窗手动同步。

只输出状态、来源、工具名称、模型、项目短名称等元数据；不输出问题、回复、工具参数、工具输出、网页标题或聊天网址。

官方本地生命周期协议：https://learn.chatgpt.com/zh-Hans/docs/hooks
